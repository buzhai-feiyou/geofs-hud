# 🚀 GeoFS HUD - Fighter-Style Head-Up Display

[![License](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)
[![GeoFS](https://img.shields.io/badge/GeoFS-Compatible-brightgreen.svg)](https://www.geo-fs.com)
[![Version](https://img.shields.io/badge/version-5.7.3-orange.svg)]()

A professional, fighter-style Head-Up Display (HUD) for GeoFS flight simulator. Fully customizable, hardware-accelerated, and designed for the best flight experience.

---

## ✨ Features

| Category | Feature |
|----------|---------|
| **Core** | Airspeed, Altitude, Vertical Speed, Heading, G-Force, Thrust, Pitch, Roll |
| **Advanced** | Attitude Indicator, Airspeed Tape, Altitude Tape, Heading Compass |
| **Customization** | Custom HUD color, Background box toggle, Opacity, Scale, Position |
| **Dual Data** | TAS/GS switchable (main + sub display), MSL/AGL switchable (main + sub display) |
| **Tape Options** | Scroll speed adjustable for airspeed/altitude tapes |
| **Attitude Indicator** | Pitch step (5°/10°), Line spacing (1-5px) |
| **Presets** | Center (no ads), Center (ads), Top-left |
| **Performance** | Uses Canvas (not DOM), Optimized rendering, No FPS drop |
| **Compatibility** | Works with Tampermonkey / Violentmonkey, Supports GeoFS default and modded aircraft |

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| `L` | Toggle HUD On/Off |
| `Shift + L` | Open Settings Panel |
| `Alt + L` | Cycle Presets |

---

## 🖥️ Settings Panel

| Option | Description |
|--------|-------------|
| Preset | Switch between layouts |
| X/Y Position | Move HUD anywhere |
| Scale | Resize HUD (0.5x - 2.0x) |
| Opacity | Set transparency (0.3 - 1.0) |
| Airspeed Tape Scroll | Adjust scroll speed |
| Altitude Tape Scroll | Adjust scroll speed (x10) |
| Attitude Step | 5° or 10° increments |
| Attitude Line Spacing | 1-5 pixels |
| Background Box | Toggle black background |
| Main Speed Display | TAS or GS |
| Main Altitude Display | MSL or AGL |
| HUD Main Color | Custom hex color picker |

All settings are **automatically saved** to your browser.

---

## 📥 Installation

1. Install a userscript manager: [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/)
2. Click [here](https://github.com/buzhai-feiyou/GeoFS-HUD/raw/main/geofs-hud.user.js) to install the script
3. Open [GeoFS](https://www.geo-fs.com)
4. Press `L` to show the HUD

---

## 🛠️ Requirements

- A modern browser (Chrome, Firefox, Edge, etc.)
- GeoFS running in 3D mode
- Tampermonkey or Violentmonkey extension

## ❓ FAQ

**Q: The HUD doesn't show up. What should I do?**  
答：确保已启用TamperMonkey，重新加载页面，然后按`L`。 检查控制台(F12)是否有错误。

**问：我可以更改HUD的位置吗？**  
答：是，使用设置面板(`shift+L`).

**问：这是否适用于GeoFS Mobile？**  
答：它可能行得通，但它针对桌面浏览器进行了优化。

**问：空中交通管制有英文版的吗？**  
a：还没有。ATC插件目前只有中文版本。

**问：这真的是最好的HUD吗？**  
答：作者认为是这样。100多名GeoFS玩家也同意。 🏆
